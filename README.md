# Ravitej — Portfolio Website

Personal portfolio website of **Ravitej**, AI & ML Engineer and Full-Stack Developer.

Live preview or deployment can be enabled using [GitHub Pages](https://pages.github.com/).

## ⚡ Highlights
- **Role**: AI & ML Engineer · Full-Stack Developer
- **Education**: B.E. in Artificial Intelligence & Machine Learning at East West Institute of Technology, Bengaluru
- **Featured Projects**:
  - [ThreatLens AI](https://github.com/Ravitej555/Threadlens-AI.git): AI-powered malware classification & threat detection platform
  - [Smart Health Advisory System](https://github.com/Ravitej555/cnrproject-.git): Health risk assessment with interactive 3D human body visualization (Three.js)

## 🛠️ Tech Stack
- **Languages**: HTML5, CSS3, JavaScript
- **Libraries**: Three.js (Canvas particles & interactive animations), Google Fonts (Syne, Inter)
- **Design**: Responsive, dark theme with glassmorphism and ambient lighting effects

## 🚀 Deployment (GitHub Pages)
1. In this repository, go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Click **Save**. Your portfolio will be live at `https://ravitej555.github.io/ravitej-portfolio/`.
